# Fotos originais

Coloque nesta pasta as fotos originais que serão avaliadas antes de entrar no site.

## Como enviar

- Envie de preferência em JPG, PNG ou WebP, sem print de tela e sem filtro adicional.
- Use nomes simples, como `foto-01-vitinho.jpg`, `foto-02-corte.jpg` e `foto-03-barbearia.jpg`.
- Não substitua diretamente os arquivos da pasta `public`.
- As imagens atuais continuam no site até as novas serem selecionadas, tratadas e publicadas.

Depois do envio, as melhores fotos devem ser otimizadas para WebP e copiadas para
`public`, mantendo os arquivos originais preservados aqui.
